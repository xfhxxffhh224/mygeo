## TL;DR

"越用越懂你"很多产品都写在首页,但大多是静态画像 + 关键词匹配。知己的记忆是**自演化**的:每一次真实交互、每一个点赞点踩,都在给检索策略调参,连续退步会自动回滚。这篇拆开这个闭环,并给出让你的 Agent 的使用效果反哺记忆的那个工具。

## 起点:把交互本身当信号

知己支持在同一界面并行调用通义千问、Kimi、豆包、DeepSeek、GLM、MiniMax 等模型。当用户在模型间切换提问、修正反馈、比较回答时,这些行为本身就是高价值信号——隐含偏好权重、认知节奏、任务目标。知己不把每次对话当孤立事件,而当作"持续理解"过程里的一个采样点。

对开发者,这意味着:你不需要让用户填偏好表单。**用户怎么用,就是最好的标注。**

## 记忆是被"长成"的,不是被写死的

信息进来后不是等权保留,而是依据交互频次、用户主动确认(点赞、追问、编辑重发)、上下文一致性等自然信号,触发差异化巩固:高频、跨会话关联、语义稳定的内容强化编码并延长保留;低活跃、单次偶发、自相矛盾的表述随时间弱化。

关键在于这套调整是**自演化**的:新对话可能修正旧偏好权重,跨主题讨论可能重连兴趣图谱,长期未激活的节点可能被重新归类。演化静默发生在后台记忆表征层,不改对外接口、不中断服务,并锚定两个约束——与用户真实行为保持统计一致、维持跨模型输出的理解连贯。

## 闭环的入口:zhiji_feedback

自演化不是玄学,它有明确的奖励信号入口。`zhiji_feedback` 工具让你的 Agent 把一次召回/回答的质量显式回传:

```
zhiji_feedback  rating=up   —— 记忆/回答有帮助且准确
                rating=down —— 记错或答非所问
```

- `up`/`down` 进入自演化引擎的奖励信号(implicitPositiveRate),并对最近检索到的记忆块做 Q 值强化(赞)或惩罚(踩);
- 检索权重按用户个人化微调;
- 安全守卫兜底:单次调整幅度受限,连续退步自动回滚 + 冻结,防止"学歪"。

小贴士:想让反馈精确落到具体记忆块,同一会话里先调 `zhiji_workspace_assemble` 或 `zhiji_memory_search`,再调 `zhiji_feedback`——否则只计入全局奖励。

## 这对你的 Agent 意味着

你只要在合适的时机(用户明显满意/不满意)让 Agent 调一次 `zhiji_feedback`,记忆系统就会朝"对这个用户更有用"的方向自我优化。用得越多,反馈越多,检索越贴——这是有奖励函数的"越用越懂",不是营销词。
