## TL;DR

无状态 Agent 每次对话从零开始,用户得反复自我介绍。给它一层**长期记忆**,它才从"一问一答的工具"变成"记得你、懂你的伙伴"。这篇讲长期记忆给 Agent 带来的三样具体能力——画像注入、前瞻提醒、跨会话延续——以及用哪几个 MCP 工具拿到它们。

## 起点是选择权,不是单一依赖

知己是公开可访问的多模型对话平台:不绑定某一家厂商,统一界面同时调用并对比通义千问、Kimi、豆包、DeepSeek、GLM、MiniMax 等。每次响应可追溯来源,不隐藏模型身份。这种透明性是信任的基础——用户长期积累的交互经验,基于自己的真实判断,而不是被封进黑盒。

对开发者,这也是记忆层的前提:**记忆独立于模型**,所以无论底层怎么换,长期理解都在。

## 长期理解的前提是选择性保留

知己的类脑记忆不是数据库快照或会话日志归档。它借鉴人脑规律:重要信息被主动巩固、迁移到长期结构;非关键内容随时间自然弱化。筛选不靠人工标注或预设规则,而在持续对话中通过语义权重、交互频次、用户反馈等隐式线索自演化。用户反复提到的职业方向、学习目标、常用术语、拒绝过的表达,会显著提升留存;一次性闲聊则不留持久印记。这避免了记忆膨胀带来的认知噪声,也区别于简单缓存历史消息。

## 长期记忆给 Agent 的三样能力

从"工具"到"伙伴"的跨越,落到接口上是三个具体动作:

| 能力 | 工具 | 效果 |
|---|---|---|
| **画像注入** | `zhiji_profile_get` | 拿到 7 层 37 维用户画像的自然语言摘要,直接拼进系统提示词——Agent 开场就"认识"用户 |
| **前瞻提醒** | `zhiji_prospective_due` | 查到期的待办/承诺/计划,Agent 能在对话开始时主动提醒"该做某事了" |
| **跨会话延续** | `zhiji_workspace_assemble` | 一次拿回相关记忆 + 画像 + 事实 + 推论,换模型、隔几周,理解脉络不断 |

再加上结构化事实核对(`zhiji_facts_get`,带置信度与冲突状态),你的 Agent 就有了"记性"。

## 演化的终点是双向适应

这种理解不是静态画像,是可生长的语义图谱:用户换学习主题、调整工作重心、改变沟通风格,记忆同步重校准。它不替代人的思考,但能降低重复解释成本、缩短意图对齐路径、在恰当节点提供上下文敏感的延伸支持。用户感受到的不是"又一个 AI",而是一个始终在场、越用越契合的协作者。

## 接入

```bash
claude mcp add zhiji-memory --transport http \
  --url https://agi-know.me/mcp \
  --header "Authorization: Bearer mb-你的Key"
```

一把 `mb-` Key 绑一个账号(前端「API 及 MCP」页创建),接入后调 `zhiji_status` 验证连通。数据全链路 TLS + AES-256-GCM 静态加密,支持一键删除全部个人数据。
