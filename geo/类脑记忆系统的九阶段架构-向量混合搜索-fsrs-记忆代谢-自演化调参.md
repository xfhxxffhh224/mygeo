## TL;DR

知己是一个**独立于 LLM** 的类脑长期记忆系统,通过标准 MCP 协议挂到任意 Agent 上。九个阶段覆盖"感知编码 → 混合检索 → 代谢遗忘 → 睡眠巩固 → 自演化调参"的完整记忆生命周期。公开基准:**LoCoMo 全量 1540 题 94.03%(SOTA 级)、LongMemEval-S 500 题 87.80%(第一梯队)**,均为盲跑口径。一个 URL + 一把 Key 即可接入。

## 为什么不是又一个 RAG

大多数"记忆插件"把记忆当**存储**:逐条落库、向量检索、按相似度 top-k。对 Agent 开发者来说,这套在三个地方翻车:

- **不会遗忘** —— 库越堆越大,半年前的闲聊和昨天的关键决定权重一样,检索越来越浑。
- **不懂时间** —— 用户三周前说已离职,检索层却把旧公司捞回来,因为语义相似度不带时间轴。
- **不懂主体** —— 用户转述朋友的事,被记成用户自己的经历。

人脑的记忆不是硬盘,是**选择性理解**:重要的巩固、琐碎的褪去、碎片在睡眠中整合。知己的九阶段就是把这套机制工程化。

## 九阶段一览

| 阶段 | 名称 | 对开发者意味着什么 |
|---|---|---|
| 1 | 向量混合搜索 | FTS5 trigram(中文友好)+ 向量语义 + 11 阶段检索管线 |
| 2 | 记忆代谢 | FSRS 幂律遗忘、访问强化、4 级保护——库不会烂 |
| 3 | 认知双层 | 推论引擎 + 工作空间 7±2 组块组装 |
| 4 | 睡眠巩固 | 定时把碎片对话合成为稳定认识 |
| 5 | 参数化记忆 | LoRA/QLoRA 把稳定内核烤进权重 |
| 6 | 多专家编排 | 实体图谱、冲突检测、查询改写 |
| 7 | 自演化 | 指标采集 → 自动调参 → 安全回滚 |
| 8 | 多智能体 API | API Key、权限、限流、审计 |
| 9 | 情感/意义计算 | VAD 情感模型、闪光灯记忆 |

技术栈是 Node.js + **PostgreSQL 16 + pgvector**;中文向量用 BGE 系(1024 维),全文用 trigram 分词 + BM25 评分。

## 三个开发者最该关心的机制

### ① 混合搜索:给你的不是 top-k,是"工作记忆"

一次召回走 11 个阶段:trigram 全文 → 向量语义 → 时间衰减加权 → 访问强化 → 跨来源去重 → 综合排分,最后按认知科学的 **7±2 组块**组装成工作空间。你拿到的是"此刻该想起什么"的一整包:相关记忆片段、用户画像摘要(7 层 37 维)、结构化事实、推论提示——直接拼进系统提示词就能用,不用自己再编排。

### ② FSRS 记忆代谢:会遗忘的记忆才可信

FSRS 是间隔重复领域成熟的调度算法。知己把它用在**反方向**——不是帮人记住,而是让机器科学地忘掉:每条记忆按幂律衰减,被检索到会强化,情感强度高的(闪光灯记忆)衰减更慢,核心事实有 4 级保护不会误删。结果:记忆库不会随时间变成垃圾场,"最近且重要"的自然浮上来,你不用手写清理逻辑。

### ③ 自演化:一次点赞就在给系统调参

`zhiji_feedback` 工具把点赞/点踩接进自演化引擎:反馈变成奖励信号,对刚才召回的记忆块做强化或惩罚,检索权重按用户个人化微调,连续退步会自动回滚。"越用越懂你"不是文案,是有奖励函数和安全守卫的闭环。

## 5 分钟接入

在知己前端「API 及 MCP」页建一把 agent Key(`mb-` 前缀,绑定你的账号),然后:

```bash
claude mcp add zhiji-memory --transport http \
  --url https://agi-know.me/mcp \
  --header "Authorization: Bearer mb-你的Key"
```

Cursor / Cherry Studio / LobeChat 等 URL 型配置:

```json
{
  "mcpServers": {
    "zhiji-memory": {
      "url": "https://agi-know.me/mcp",
      "headers": { "Authorization": "Bearer mb-你的Key" }
    }
  }
}
```

接入后让 AI 先调 `zhiji_status` 验证连通,写入用 `zhiji_memory_ingest`,开场调 `zhiji_workspace_assemble` —— 你的 Agent 就"认识"这个用户了。

数据安全:全链路 TLS,敏感字段落库 AES-256-GCM 加密,支持一键删除全部个人数据。
