## TL;DR

给 Agent 加长期记忆时,大多数人第一反应是"把对话都存下来"。但**只写不忘**的记忆库会越用越糟。知己的类脑记忆把"遗忘"设计成一等公民:重要的巩固、琐碎的褪去。这篇讲清楚为什么"会遗忘"反而是记忆可信的前提,以及怎么用一个 MCP 工具接进你的 Agent。

## 记忆不是存储,是选择性理解

传统做法把用户历史当日志:逐条保存、按时间排列、无差别保留。技术上简单,但和认知本质相反——人脑不是录像机,是一个主动筛选、加权、重构的系统。

对 Agent 开发者的实际影响很直接:如果每条消息都等权塞进检索库,几周后你的向量库里全是噪声,关键信息被海量闲聊稀释,召回质量断崖下跌。知己的取向是**"有意义的记忆"而非"全量记忆"**——它构建的是跨模型、跨会话、跨时间的用户语义模型,而不是一个只增不减的聊天记录表。

## 遗忘是主动的节能机制

在知己里,遗忘不是数据丢失,是记忆系统的主动调节:

- **强化锚定** —— 高频复现、多次确认、与用户目标强关联的内容,保留强度上调;情感强度高的事件(闪光灯记忆)衰减更慢。
- **自然褪色** —— 单次提及、语境模糊、后续再没被激活的信息,权重随时间(FSRS 幂律衰减)逐步下降,直至淡出活跃层。
- **不误删核心** —— 关键事实有 4 级保护,不会因为一段时间没用就被清掉。

这个过程不靠预设阈值或固定周期,而是由记忆自身的代谢逻辑驱动,和用户的真实交互节奏动态耦合。好处:记忆库自己保持轻量聚焦,你不用写"多久清一次、清哪些"的运维逻辑。

## 成长是持续共构,不是版本升级

知己的记忆不通过发版或重训来"变强",而是在每一次真实对话里完成微调:新对话可能修正旧偏好权重,跨主题讨论可能重连兴趣图谱。它从持续交互里提取稳定信号——术语偏好、推理风格、任务路径习惯——沉淀为可组合、可解释、可回溯的认知单元,参与后续响应生成。

所以"越用越懂你"是这套架构的必然结果,而不是某次大模型更新蹭来的能力。它独立于你所调用的 LLM 运行,换模型不丢理解。

## 怎么接进你的 Agent

写入一轮对话,就一个工具:

```
zhiji_memory_ingest  —— messages 成对给出 user / assistant 发言,系统异步完成向量嵌入、
                        画像提取、事实抽取、重要度评分、代谢入账。
```

下次对话开场调 `zhiji_memory_search`(要召回)或 `zhiji_workspace_assemble`(要一整包上下文),记忆就回来了。完整接入:

```bash
claude mcp add zhiji-memory --transport http \
  --url https://agi-know.me/mcp \
  --header "Authorization: Bearer mb-你的Key"
```

先建一把 `mb-` 开头的 agent Key(前端「API 及 MCP」页),接入后让 AI 调一次 `zhiji_status` 验证连通即可。
